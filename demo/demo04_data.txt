:= TI-84 Plus
:
  * Texas Instrumentsのグラフ電卓
:
  * 同じZ80
:
  * クロックも速くRAMも多い
:
  * ROMがない(のかもよくわかってない)

:= AOT Compilation
:
  * 高速化がしたかった
:
  * 高速化のカギは事前計算
:
  * 事前計算を頑張るとAOTコンパイルに行き着く
:
  * fetch, decode,
    dispatch, execute

    dispatchまではビルド時にできる
:
  * 単に最近流行っているのでやってみたかった
:
  * ただ、RubyからCは色々足りない(Parserなど)
:
  * バイトコードからCのAOTコンパイラ
:
  * 基本コーディングエージェント任せ(最近の流行)
:
  * 速くてでかい
:
  * 高速化にはROM容量というコストがかかる

:= 日本語表示について
:
  * 今回約250種の文字から約440種にサポートを拡大した
:
  * マスターシステムはタイルベースのグラフィック
    (最大448タイル)
:
  * 元々は1バイトで1文字とした
:
  * 約250種の文字に収めるため「使う字だけ持ってくる」
:
  * オレオレエンコーディングになる
:
  * 今回9ビットで1文字とした。正直気持ち悪い
:
  * 16ビットでもできるが無駄が多い

    ROM容量は限られている
:
  * ひたすら詰め込んでRAMに展開するとRAMが足りない
:
  * 9バイトで8文字という変則エンコーディング

:= Z80について
:
  * 8-bit CPU
:
  * 1976-2024
:
  * 16ビットと8ビットのレジスタ
:
  * ある機能

    Fレジスタ、BCD命令、裏レジスタなど
:
  * ない機能

    割り算、掛け算、浮動小数点
